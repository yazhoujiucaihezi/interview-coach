# 面试陪练台

把面试记录、简历、README、项目简介丢进去，自动解析材料，由大模型按**材料里的具体内容**出题，开口练习后打分。

单文件、纯前端、无需构建、无需后端。

**在线使用**：<https://yazhoujiucaihezi.github.io/interview-coach/>

---

## 它解决什么问题

网上的面试题库都是通用的，问你「HashMap 原理」，但没人问你「你说热榜用 ZSet 存 postId→分数，7 天以外的成员怎么清理」。

这个工具反过来：**先读你的材料，再出题**。题目会锚定你写过的模块、用过的技术、写下的数字，并且每道题都带 `quote` 指回原文。

---

## 四类材料

| 材料 | 出什么题 |
|---|---|
| **面试记录** | 复盘模式：统计追问、短回答、口头禅；把面试官问过的问题变成可练的题，附你当时的回答 |
| **简历** | 按「项目经历」逐个出「这个项目你负责哪部分 / 最难的点」；揪出技能条目问原理；把每个数字问成「怎么测的」 |
| **README / 项目简介** | 按功能模块出「这块怎么实现的」，从技术栈出「为什么用 X，考虑过别的吗」 |
| **通用 Markdown** | 按标题出「用 1 分钟讲清楚 X」 |

类型自动判断，判错了可以在概览页顶部手动切换。

> 没有接入模型时**不会出题**。宁可空着，也不给你一堆「介绍一下你自己」的模板题。

## 快速开始

1. 打开页面，点左下角「设置」
2. 填三个字段，点「测试连接」：
   - **Base URL**：`https://api.deepseek.com/v1`
   - **API Key**：你的 key
   - **模型名**：`deepseek-chat`
3. 回到「导入」，把 `.md` 拖进去
4. 等十几秒，模型读完材料直接出题

题目会存在浏览器里，刷新不丢；概览页可以「导出题单」成 Markdown。

## 连不上怎么办

先点设置页的 **「网络自检」**。它会在 10 秒内给出结论，比逐个猜快得多：

- 它会用 `no-cors` 方式同时探测**你填的接口**和**一个对照接口（智谱）**，这一步不触发预检，只要网络层能到就一定成功。
- 两个都通 → 网络没问题，是**浏览器把请求拦下来了**（扩展、跟踪防护，或者在应用内预览面板里打开）。
- 只有一个不通 → **那条域名在你网络里被拦**（DNS、公司网关、代理软件规则），跟 CORS 无关。
- 两个都不通 → 本机到外网 API 的链路断了，检查代理软件和 DNS。

DeepSeek 官方对跨域是放行的（预检和实际响应都会回显 `Origin`，连 `Origin: null` 都放行），所以报错基本不会是它拒绝跨域。

按自检结论处理：

1. **地址格式**：必须是 `https://` 开头、`/v1` 结尾，**不要带** `/chat/completions`。
   设置页会实时显示「实际请求：https://...」，对照一眼就能看出错在哪。
2. **浏览器扩展**：广告拦截、隐私保护类插件会拦掉这类请求。
   Edge 还要在「设置 → 隐私、搜索和服务 → 跟踪防护」里对这个站点关闭。
3. **换个环境验证**：用 Chrome 无痕窗口打开线上地址。如果只在应用内预览面板里失败，就是那个面板的 CSP 限制，换浏览器打开即可。
4. **上本地代理**：见下一节。设置页有「用本地代理」按钮，一键把地址改成 `http://127.0.0.1:8787/v1`。

各家服务商的 Base URL：

| 服务商 | Base URL | 模型名示例 |
|---|---|---|
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| Moonshot | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 通义千问 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen-plus` |
| OpenRouter | `https://openrouter.ai/api/v1` | 任选 |

## 报「不是合法 JSON」怎么办

出题要求模型返回结构化 JSON，模型偶尔会写坏：包了一层 markdown 围栏、加了句「好的，这是题目」、字符串里带了裸换行、末尾多了个逗号，或者**输出太长被 max_tokens 截断**。

页面里做了四层处理，正常情况下你不需要管：

1. **去噪**：剥掉围栏、去掉前后说明文字，只留 `{...}` 主体
2. **修补**：中文引号当结构引号、字符串内换行转义、去尾逗号、补全未闭合的括号
3. **抢救**：如果输出确实被截断，逐个提取已经完整的题目对象，有几道用几道，卡片上会注明「输出被截断，已保留完整的 N 道」
4. **自动重试**：以上都不成立时，自动用更少的题量（8 道）再请求一次

仍然失败，多半是模型本身不稳（比如小参数模型）。换成 `deepseek-chat` 或 `glm-4-flash` 基本就正常了。

## 本地代理（浏览器实在不让你直连时用）

仓库里带了一个转发脚本，只需要 Node 18+，没有任何依赖。

```bash
node proxy.mjs                                   # 默认转发 DeepSeek
node proxy.mjs https://open.bigmodel.cn/api/paas/v4
```

启动后把页面里的 Base URL 改成 `http://127.0.0.1:8787/v1`（设置页有「用本地代理」按钮，一键填好）。

- 代理只监听 `127.0.0.1`，外部访问不到
- 请求体和 API Key 只在内存里过一遍，不写磁盘、不做日志（只在终端打一行状态码）
- 浏览器打开 `http://127.0.0.1:8787/health` 能返回 `{"ok":true}` 就说明代理活着
- 端口被占用时换一个：`PORT=8788 node proxy.mjs`
- 目标地址里已经带了 `/v1` 也不会拼成 `/v1/v1`，会自动去重

## 数据与隐私

- **纯前端**，没有后端服务器，没有统计脚本，没有第三方请求（除了你自己配置的模型接口）
- 导入的材料、生成的题目、练习记录，全部存在浏览器的 `localStorage`
- API Key 同样只存在本机浏览器，随请求发给**你自己填的那个接口**
- 清除浏览器数据 = 全部清空；重要记录请先导出

## 实现说明

- 单 HTML 文件，无框架、无构建步骤、无 CDN 依赖，可以直接双击打开，也可以丢到任意静态托管
- 材料解析：按 `#` 标题切段、抓 `00:03:24` 时间戳、识别 `**面试官**：` / `**我**：` 这类说话人（先统计粗体标签出现频次再推断，不写死人名）
- 出题：把材料（超长时取头尾）连同「禁止通用题」的约束发给模型，要求每题返回 `q / why / points / quote / level`；`max_tokens` 给到 4000，单次 12 题，避免输出被截断
- JSON 解析：自带容错解析器（剥围栏 → 定位结构 → 修补转义/尾逗号/未闭合 → 逐条抢救 → 自动重试），不依赖模型「一次写对」
- 评分：把题目、答题要点、你的回答一起发给模型，按准确性 40% / 完整性 30% / 结构 15% / 深度 15% 打分
